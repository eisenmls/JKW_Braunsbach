# Kulturweg Braunsbach

Android app for the Jüdischer Kulturweg Braunsbach, a walking tour of Jewish history in Braunsbach with stations 0 to 9. All user-facing text is in German.

The app is a static website in `www/`, wrapped with Capacitor so it works offline. There is no framework and no web build step.

- App name: JKW Braunsbach
- App ID: `app.kulturweg.braunsbach`. It must match the live Google Play listing, so don't change it.
- Google Play listing: "Jüdischer Kulturweg Braunsbach" by EisenmannIT
- Repo: https://github.com/eisenmls/JKW_Braunsbach (public)

Setup steps for a new computer are in `README.md`.

## Commands

Run from the repo root on Windows. Use `npm.cmd`, because PowerShell may block plain `npm`.

| Command | What it does |
|---|---|
| `npm.cmd run apk` | Installs packages, syncs `www/` and builds a debug APK |
| `npm.cmd run aab` | Installs packages, syncs `www/` and builds the signed app bundle for Google Play |
| `npm.cmd run phone` | Builds and installs on a phone connected by USB |

The APK ends up at `android\app\build\outputs\apk\debug\app-debug.apk` and the app bundle at `android\app\build\outputs\bundle\release\app-release.aab`.

The `apk` and `aab` scripts call `gradlew.bat`, so they only work on Windows.

There are no automated tests. To check a change, review the `www/` folder, for example by opening `www/index.html` in a browser at phone size. Don't build the APK or app bundle, start the emulator or install on a phone unless the user asks for it. Final checks belong on a real phone.

## Rules

- Edit website content in `www/` only. `android/app/src/main/assets/public/` is generated by `npx cap sync`.
- Don't edit `android/app/capacitor.build.gradle`. Capacitor regenerates it.
- Name media `station-NN-MM-description.ext`, or `sonstiges-MM-description.ext`, using lowercase letters, digits and hyphens only. `NN` is the tab number, which can differ from the numbers in the old source files.
- Match upper and lower case exactly in media links. Windows ignores case and Android doesn't.
- Keep photos to about 1600 px on the long side. Keep full-size originals outside this repo.
- The station numbers in the app differ from some sign numbers on purpose. It's the order the museum wants, so leave them as they are.
- Never commit signing keys. `.gitignore` blocks `*.jks`, `*.keystore` and `key.properties`.
- The app must work offline. Don't load fonts, scripts or anything else from the internet.

## Design

The idea is "Stein und Glas", taken from the Braunsbacher Denksteine in Station 8: limestone pages, dark glass and the sloped break edge of the stones. The blue comes from the menora on the trail signs. Colors are tokens at the top of the CSS, and dark mode follows the phone's setting.

- Headings and Hebrew use Frank Ruhl Libre. Body text and controls use Source Sans 3.
- Text size is set in `rem`, so the "Aa" button scales it.
- Audio is a `<button class="track" data-src="...">` with a title and duration. One shared `Audio` object plays it, so it keeps running when the visitor changes station.
- Images open in the zoom viewer when tapped. Figures use one of four classes: `breit` for wide photos, `hoch` for tall photos, `dok` for documents and `klein` for small images. A `blatt` div makes a row of images that scrolls sideways.
- Each station's header image has `class="hero-img"`. It's a gray, tinted crop of a photo from the station. Station 8 has no photo, so its header is a drawn SVG of the stones.
- The route and station stones on the Start page are inline SVG in `index.html`, on top of the base map.
- The map data comes from OpenStreetMap (ODbL) and the contour lines from Copernicus DEM GLO-90. The credit in the Impressum and under the map has to stay.

## Toolchain

| Tool | Version |
|---|---|
| Java | 25, from Android Studio's `jbr` folder |
| Gradle | 9.8.2 |
| Android Gradle Plugin (AGP) | 9.5.0 |
| Capacitor | 8.6.0 |
| Target and compile SDK | API 37 (Android 17) |
| Minimum SDK | API 24 (Android 7.0) |

These versions depend on each other:

- Java 25 needs Gradle 9.1 or newer. Gradle 8.14 fails with `Unsupported class file major version 69`.
- API 37 needs AGP 9.1 or newer.
- Capacitor 8 ships with AGP 8.13. `android/build.gradle` overrides it for all modules with 9.5.0, even though Capacitor's own files in `node_modules` still list 8.13.
- AGP 9 needs `proguard-android-optimize.txt` in `android/app/build.gradle`, not `proguard-android.txt`.
- The app's code compiles at Java 21 level, because Capacitor sets that. Java 25 only runs the build.
- The build shows deprecation warnings that will become errors in Gradle 10. Upgrade Capacitor before moving to Gradle 10.

When Capacitor 9 is stable, upgrade with `npx cap migrate`.
